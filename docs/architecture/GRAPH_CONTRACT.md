# Canonical Graph Contract Specification

Version: `1.0.0`

## 1. Overview
The Canonical Graph is the authoritative data model generated by the PreBase Rust backend and consumed by the frontend visualizations (Network and Temporal). The backend is the sole source of truth for repository structure.

## 2. Directional Invariant
For any internal dependency where file `A` imports or references file `B`:
- **Edge Direction**: `A` -> `B` (`source_file_id = A`, `target_file_id = B`).
- **Dependencies (Outgoing)**: The files that `A` imports.
- **Dependents (Incoming)**: The files that import `A`.

## 3. Data Entities

### 3.1 `RepositoryInfo`
```json
{
  "repository_id": "sha256-hash-or-slug",
  "repository_root_display": "my-project",
  "repository_name": "my-project",
  "analysis_revision": 1,
  "indexing_status": "Ready"
}
```

### 3.2 `FileNode`
Represents a source file discovered and indexed in the repository:
```json
{
  "id": "src/index.ts",
  "relative_path": "src/index.ts",
  "filename": "index.ts",
  "language": "typescript",
  "size_bytes": 1024,
  "file_kind": "source",
  "analysis_status": "Analyzed",
  "direct_dependency_count": 3,
  "direct_dependent_count": 0
}
```

### 3.3 `DependencyEdge`
Represents a confirmed directed dependency between two indexed internal files:
```json
{
  "id": "src/index.ts->src/utils/math.ts",
  "source_file_id": "src/index.ts",
  "target_file_id": "src/utils/math.ts",
  "relationship_kind": "Import",
  "resolution_status": "ResolvedInternal",
  "evidence": [
    {
      "source_file_id": "src/index.ts",
      "import_specifier": "./utils/math",
      "line": 4,
      "column": 1,
      "relationship_kind": "Import",
      "is_type_only": false
    }
  ]
}
```

### 3.4 `AnalysisCoverage`
Provides transparency on scanned vs analyzed vs excluded files:
```json
{
  "total_discovered": 45,
  "total_analyzed": 42,
  "total_excluded": 3,
  "total_issues": 1,
  "is_complete": true
}
```

### 3.5 `AnalysisIssue`
Records parser errors, unresolvable imports, or policy exclusions without inventing fake edges:
```json
{
  "file_path": "src/legacy.js",
  "issue_kind": "UnresolvedImport",
  "message": "Cannot resolve import './missing-helper' from src/legacy.js",
  "line": 12,
  "column": 8
}
```

### 3.6 `GraphSnapshot`
The full snapshot delivered over the API:
```json
{
  "schema_version": "1.0.0",
  "repository_id": "repo-id",
  "revision": 1,
  "nodes": [...],
  "edges": [...],
  "coverage": {...},
  "issues": [...]
}
```
