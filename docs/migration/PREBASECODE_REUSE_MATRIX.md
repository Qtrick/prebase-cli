# Prebasecode Component Reuse and Migration Matrix

| Existing Component | Current Implementation & Dependencies | Migration Strategy | Target Destination | Verification Method |
|---|---|---|---|---|
| `graphs/src/core/scanning/projectFiles.ts` & `ignorePatterns.ts` | TypeScript filesystem walker + glob ignore list. Coupled to Node.js `fs` / VS Code URI. | **Rust Reimplementation** | `crates/prebase-core/src/scanner.rs` | Unit & integration tests verifying ignored directories (`.git`, `node_modules`, `dist`, `.reference`, etc.), secret-file exclusion (`.env`, `*.pem`), and traversal safety. |
| `graphs/src/core/parsing/importExtractors.ts` & `parserEngine.ts` | Brittle regex-based extractors for multiple languages, coupled to Node worker pool. | **Rust Reimplementation** | `crates/prebase-parser/src/lib.rs` | Tree-sitter JS/TS/TSX/JSX parser suite with AST queries for static imports (`import { x }`, default, namespace, side-effect, type-only) and static re-exports (`export ... from`). Unit tests with golden AST fixtures. |
| `graphs/src/core/resolution/importResolution.ts` & `tsconfigPaths.ts` | TypeScript fuzzy/heuristic path resolution with regexes. | **Rust Reimplementation** | `crates/prebase-parser/src/resolver.rs` | Clean module resolver testing exact relative paths, extensionless substitutions (`.ts`, `.tsx`, `.js`, `.jsx`), directory `index` resolution, and `tsconfig.json` `baseUrl` / `paths`. |
| `graphs/src/core/canonical/canonicalGraphAnalyzer.ts` | TypeScript graph builder creating canonical snapshots, node IDs, and edge digests. | **Rust Reimplementation** | `crates/prebase-core/src/graph.rs` | Canonical Graph contract tests verifying deterministic node/edge IDs, strict directional edge invariant (A imports B: A -> B), deduplication, and unresolved import handling. |

| `graphs/src/common/types/canonicalTypes.ts` & `graphTypes.ts` | TypeScript interface definitions for nodes, edges, snapshots, coverage, and layout positions. | **Adaptation & Shared Contract** | `contracts/graph-schema.json`, `crates/prebase-core/src/model.rs`, `frontend/src/types/graph.ts` | Serde JSON round-trip tests and TypeScript type checking confirming identical contract semantics. |
| `graphs/src/common/constants/fileTypeColors.ts` | Pure TypeScript language color map, file extension mappings, and entry node styling. | **Direct Reuse** | `frontend/src/graphs/network/fileTypeColors.ts` | Visual inspection and frontend unit tests matching expected file extension colors (TS, JS, CSS, JSON, etc.). |

| `graphs/src/layouts/network/sphereLayout.ts` & `constellationLayout.ts` | Deterministic Fibonacci sphere and constellation layouts in pure TypeScript. | **Direct Reuse** | `frontend/src/graphs/network/layout/` | Determinism unit tests for 3D/2D projection. |
| `graphs/src/view/network/networkRenderMath.ts` | Pure TypeScript 3D projection, depth scaling, semantic weight, and zoom-compensated visual radius math. | **Direct Reuse** | `frontend/src/graphs/network/render/networkRenderMath.ts` | Visual radius and perspective projection unit tests validating parity with Prebasecode baseline. |
| `graphs/src/view/network/networkEdgeVisual.ts` | Pure TypeScript single-source-of-truth resolver for edge colors, widths, alpha, dashes, and directional arrows. | **Direct Reuse** | `frontend/src/graphs/network/render/networkEdgeVisual.ts` | Parity tests verifying highlighted, entry-incident, dynamic, dependency, and default import styling. |
